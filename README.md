# 💱 Currency Travel Bot — финансовый помощник для путешествий

Бот ВКонтакте для управления бюджетом в поездках: создаёт «кошельки» для разных стран, конвертирует валюты по актуальному курсу exchangerate.host, учитывает расходы и показывает остатки в двух валютах.

## Возможности
- 🧳 Создание путешествий: страна отправления → страна назначения (валюты определяются автоматически)
- 📈 Актуальный курс через API exchangerate.host + ручной ввод курса
- 💰 Стартовый баланс сразу в двух валютах
- 💱 Любое число в чате = расход в валюте страны пребывания (с подтверждением)
- 📜 История расходов с датами и суммами
- 📋 Несколько путешествий с переключением
- 🔘 Меню с кнопками + слэш-команды: /start /newtrip /switch /balance /history /setrate

## Технологии
Python, VK Bottle (Long Poll API), SQLite, exchangerate.host API, requests, python-dotenv

## Структура проекта
- `bot.py` — бот ВКонтакте: команды, кнопки, диалоги
- `current_api.py` — модуль API курсов валют (курсы и конвертация)
- `database.py` — SQLite: путешествия, балансы, история расходов
- `requirements.txt` — зависимости
- `.env.example` — пример конфигурации

## Запуск
1. `pip install -r requirements.txt`
2. Скопировать `.env.example` в `.env` и вписать свои ключи:
   - `CURRENCY_API_KEY` — ключ exchangerate.host
   - `VK_BOT_TOKEN` — токен сообщества ВК (Long Poll API, права «сообщения»)
3. `python bot.py`

## Пример диалога
Создание: Россия → Китай, курс 1 RUB = 0.0796 CNY, сумма 4000 → баланс 4000.00 RUB = 318.62 CNY.
Расход: 50 → «50.00 CNY = 627.71 RUB, учесть?» → Да → остаток 268.62 CNY = 3372.29 RUB.
